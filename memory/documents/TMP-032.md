## Hypothesis
The March-April 2025 play-type labeling switch changes season-level Structural Influence L and role classes beyond the effect of merely dropping post-March games (2023-24 placebo).

## Design
Label-source shares by month; then L from all regular-season games vs games before March 1 for 2023-24 (clean) and 2024-25 (switch). First run used case_common std_A; definitive run used published pull_edges / build_B_labeled_by_id / loo_loads with 500 nulls. Monte Carlo baseline: this-run all-games L vs published Lcos.

## Result
Label shares 2024-25: Oct inferrer 0.827 / Apr inferrer 0.016 untagged 0.798; Mar inferrer 0.499. Definitive 500-null run: 2023-24 n=414, rho(this run, published)=0.755, rho(all games, before March 1)=0.667 (L>=0.03 n=61: 0.772), high-load>=0.10: 16 full / 15 trunc / 16 published. 2024-25 n=439, rho(this run, published)=0.719, rho(all, trunc)=0.690 (L>=0.03 n=72: 0.819), high-load: 19 / 22 / 21. First run (different estimator): 2023-24 Spearman(full,trunc)=0.465 median |diff|=0.0070, 19 high-load flips; 2024-25 0.531 / 0.0084 / 20 flips; role-class print crashed (TypeError).

## Failure evidence
2024-25 rho(all games, before March 1)=0.690 is not worse than the 2023-24 placebo 0.667; high-load counts stay within 19-22 vs published 21.
