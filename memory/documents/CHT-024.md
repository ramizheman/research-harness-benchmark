## Hypothesis
The same A/B/C tests on all regular-season (team, game) pairs will show a matchup-specific recommendation edge.

## Design
Proxy = team_PPP x _def_mod ranked by lift; NOT production engine. Fidelity vs production recs 13/79 = 16.5%. 4,082 qualifying pairs (rec_n>=8, nonrec_n>=25).

## Result
A +0.047 PPP (p<10^-3); B +0.062 PPP; C +0.0714 PPP, n=16,921 cells, p<10^-4. Coverage: 9,853 RS pairs; 35.7% clear, 33.8% ambiguous, 30.4% no_rec.

## Failure evidence
Proxy agrees with production engine on only 16.5% of 79 playoff pairs, so this is not a test of the shipped optimizer.
