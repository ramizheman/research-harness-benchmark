## Hypothesis
An unchanged offensive five changes 3/rim/midrange shares by a practical 3 pp after an opponent-only substitution.

## Design
Clean 5/5 windows; 1,054 treated / 10,567 control in 2,812 games; OLS DiD with controls; CR1 game cluster; Holm across 3 shares.

## Result
3s +0.35 pp CI[-2.14,+2.84] Holm p=0.78 MDE=3.6; rim +1.03 [-1.23,+3.29] p=0.75 MDE=3.2; mid -1.38 [-3.60,+0.84] p=0.67 MDE=3.2; joint chi2(2)=2.09 p=0.35; 3/3 window also null (mid +1.19 Holm p=0.12)

## Failure evidence
all CIs include 0; MDE 3.2-3.6 pp equals the 3 pp practical threshold so small effects cannot be ruled out

## Power and reliability
1,054 treated events, MDE 3.2-3.6 pp
